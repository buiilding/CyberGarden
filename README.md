# Personal home — local prototype

A quiet personal home with loosely connected pages, short notes, links, images, and unfinished text. All names and content are neutral placeholders. No publication schedule, reading-time labels, or personal biography is assumed.

Run from this directory:

```sh
python3 -m http.server 4181 --bind 127.0.0.1
```

Open http://127.0.0.1:4181. The home page, all-pages list, individual pages, and related-page links work locally. Content lives in index.html; page titles and connections are in script.js. No dependencies, remote fonts, analytics, or hosted services are used. This is a visual prototype, not a content editor.
